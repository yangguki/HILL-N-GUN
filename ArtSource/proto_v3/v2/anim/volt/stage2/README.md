# Volt stage2 — roll 6 / throw 5 / down 6 × down·up·side
- 같은 규격(128x128, 기준점 (64,124), 키 112px), 1단계 파츠 재사용
- roll: 웅크림 → 몸 전체 회전 50/140/230/320° → 일어섬. 1~4 프레임 무적 권장
- throw: 왼팔(아래·위는 화면 오른쪽 팔)로 던짐, 2번 프레임에서 다이너마이트가 손을 떠남 → release_frame=2, release_px(meta), hand_px 프레임별
- down: 피 없음. 튀어오르며 넘어지고 정비사 모자가 날아가 머리 뒤에 떨어짐, 마지막 프레임에 X 눈(down·side) + 별 3개(머리 위). up(뒷모습)은 얼굴이 안 보여 별만
- 볼트는 넘어져도 블래스터를 손에 쥔 채(총 떨어뜨림 없음)
- 누운/구르는 프레임 기준점: 몸 bbox 가로 중앙을 x=64, 가장 낮은 픽셀을 y=124에 맞춤(발 기준 아님). head_px_last = 마지막 프레임 머리 위치
- 렌치는 회전·넘어짐 중에도 같은 오른쪽 어깨에 붙어 같이 돎
- fps: roll 12 / throw 12 / down 10, 모두 비루프(마지막 프레임 유지)
