- 같은 규격(128x128, 기준점 (64,124), 키 112px), 1단계 파츠 재사용 + 망토 레이어 별도 흔들림
- roll: 웅크림 → 몸 전체 회전 50/140/230/320° → 일어섬. 1~4 프레임 무적 권장
- throw: 2번 프레임에서 다이너마이트 손을 떠남 → release_frame=2, release_px(meta). hand_px 프레임별
- down: 피 없음. 튀어오르며 뒤로 넘어지고 모자가 날아감(뒤쪽에 떨어짐), 마지막 프레임에 X 눈(down·side) + 별 3개. up(뒷모습)은 얼굴이 안 보여 별만
- 누운/구르는 프레임 기준점: 몸 bbox 가로 중앙을 x=64, 가장 낮은 픽셀을 y=124에 맞춤(발 기준 아님). head_px_last = 마지막 프레임 머리 위치
- down 방향(정면)은 총을 손에 쥔 채 넘어짐(총 아래 몸통 메움 자국이 보이지 않게). side·up은 총이 바닥에 떨어짐
