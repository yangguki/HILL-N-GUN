# Persp2D art (slice K)

Original in-house perspective-2D assets for the Greybox proto (characters + environment).
Source package: `_tmp_slice_k/final_skins_2d/` (manifest at copy time).

- Character cells: 768×768, pivot `(0.5, 0.21875)`, PPU `351.88`.
- Environment layout: `Environment/hng_env_layout_2d.json` (design reference; runtime uses scene subset).
- UI/FX: references `Greybox3D/Art/UI` and `Greybox3D/Art/FX` (not duplicated).
- Backdrop: `Environment/Backdrop/hng_env_backdrop_sunset_strip.png` from `final_skins`.
- Atlases: `Atlases/Persp2D_CharHeroAtlas`, `Persp2D_CharBanditAtlas` (ASTC 6×6 on Android).

No Kenney character art in this folder.
