# 힐앤건 v4 그레이박스 — 화면 시안 스펙 (2026-11-20)

- 상태: **디자인만**. 구현은 이 시안을 사용자가 고른 뒤에 진행한다.
- 기준 해상도: **1920×1080 (16:9)**. 카메라 Orthographic Size 5, 화면 세로 = **10 wu**, 가로 ≈ **17.78 wu**.
- 변환: 화면 높이 1% = 0.10 wu. 화면 위가 0%. 월드 y는 화면 아래가 0일 때 `world_y = (100 − screen_y%) / 10`.
- 권장 안: **플레이어 높이 B 19%**. A 15% / C 22%는 비교용. 현재 구현 27%는 과대해 이번 시안에서 제외.
- 시안 파일은 같은 폴더. `render_mockups.py`로 다시 그릴 수 있다.
- 폰트: Gothic A1 (한글 포함). 없으면 Noto Sans CJK KR.

## 3. HUD (자리 유지, 스타일만 정리)

반투명 원. 라벨은 원 안 하단. 솔리드 상단 바는 쓰지 않는다.

## 4. 결과 화면 (글자가 반드시 보여야 함)

현재 프로토의 실패 지점이다. 아래 레이아웃·대비를 그대로 맞춘다.

- 월드와 HUD를 어둡게 깐 뒤, **가운데 카드만** 올린다. DOWN 변형 작은 카드는 이 시안의 비교용 삽입이며, **게임 안에서는 CLEAR / DOWN 중 하나만** 같은 레이아웃으로 띄운다.
- 메인 패널: x **28–72**, y **16.5–80**. 둥근 모서리, 채움 `#10121A` 약 92% 불투명, 얇은 크림색 테두리 `#DCD2B4`.
- 타이틀: 중앙, y **24.5**. `STAGE CLEAR`는 `#F5DC8C`, `DOWN`은 `#D67070`. 1080p 기준 약 52pt Black.
- 타이틀 아래 짧은 금색/로즈 가로선 (y ≈ 29.2, 폭 약 36%).
- 스탯 4행 (라벨 왼쪽 x 34.5, 값 오른쪽 x 65.5):

  | 행 | y | 라벨 | 값 예 (CLEAR) | 값 예 (DOWN) |
  |---|---|---|---|---|
  | 1 | 36 | SCORE | 800 | 300 |
  | 2 | 43 | WAVE | 3 / 3 | 2 / 3 |
  | 3 | 50 | 생존 시간 | 1:24 | 0:52 |
  | 4 | 57 | 처치 | 8 | 3 |

  라벨 약 22pt Medium `#C4C8D2`, 값 약 26pt Bold `#E6E8EE`. 행 사이 얇은 구분선. 점수는 처치 × 100 (범위 문서).
- 힌트: 중앙 y **70.5**, 약 20pt Medium. 문구 그대로 **`R  /  탭하여 다시 시작`**.
- 텍스트는 패널 위에서 무조건 앞에 그린다 (sorting / alpha / 파괴된 플레이어 참조로 글자가 사라지지 않게).

## 6. 구현 시 주의

1. **플레이어 프리팹 높이만** 27% → 19%(또는 사용자가 고른 A/C)로 줄인다. 상자·울타리·적 11%·카메라 사이즈는 그대로.
2. 몸폭도 높이 비율(×0.30)을 따라 줄인다. 폭을 8%에 고정하면 19% 키에 비해 뚱뚱해 보인다.
3. 플레이어는 조이스틱(x 4–19)과 버튼(x 77+) 밑에 서거나 구르지 않는다. 근거리 상자 오른쪽 끝(x 69)과 버튼 왼쪽(x 77) 사이 간격을 유지한다.
4. 적 팝업 엄폐는 지금 구도에서 **원거리 상자 하나**뿐이다. 중단 상자는 울타리 아래 플레이어 쪽이다.
5. 조준 드래그 영역(지금 구현은 화면 상단 40%, 문서는 오른쪽)은 이 시안에 그리지 않았다. 플레이 후 결정.
6. 아군탄 0.09 wu는 의도적으로 작다. 폰에서 안 보이면 트레이서를 먼저 확인하고, 키울 때는 0.11–0.12 정도만. 0.15로 되돌리지 말 것.
