## Animations

Clips are taken from the male-g FBX and played with the existing Playable-graph driver (no AnimatorController):

| Game state | Clip |
| --- | --- |
| Idle | `idle` (loop) |
| Move | `walk` (loop; playback speed still scales with ground speed) |
| Fire | `holding-right-shoot` |
| Hit flash | `fall` |
| Death | `die` (plays, then holds the last frame) |
| Roll | no roll take in the pack — keeps the existing procedural spin/tilt on the root. `jump` is imported and catalogued as `MiniJump` but is not required for travel. |

`sprint` is also imported on the catalog (`MiniSprint`). Characters face the current aim point (or a small move yaw if aim is unset).
