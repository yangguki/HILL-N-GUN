## Spec
1. Joystick 360° analog movement (TopDown 난전 and Frontline). Accel/decel ≈0.08 s (velocity smoothing toward target, time constant ~0.08 s), no sliding on direction change (direction snaps; only magnitude ramps), max move speed unchanged. Frontline only limits movement bounds (existing clamp); facing is free in both scenes.
2. Facing set: down, up, side (left/right via flip_x). Angle split: |angle from horizontal| <= 45° → side; above → up; below → down. Apply ≈10° hysteresis at the ±45° boundaries (stay in current facing until the angle crosses the boundary by 10°) so frames don't flicker.
3. Facing source: aim direction while aiming or shooting, otherwise move direction; when neither, keep last. After any facing change, hold the new facing ≈0.15 s minimum (min hold) before another change.
4. Animation: idle (4f, meta fps, loop) when stopped; run (8f, loop) when moving, playback rate = 12 fps × clamp(actualSpeed / maxSpeed, 0.6, 1.2) (clip base fps from meta, 12). shoot (3f once, meta fps) while shooting — shoot overrides idle/run upper presentation for its duration; backpedal shooting allowed (facing = aim, movement any direction). If simple: while shooting play shoot frames; when shoot ends return to idle/run.
5. Foot pivot (64,124) of the 128×128 frames → Sprite pivot (0.5, 4/128=0.03125). Keep existing Y-sort and the ≈13% screen-height size (hero ≈141 px at 1920×1080) — choose PPU/scale so the new frames render at the same on-screen height as the current pose sprites.
6. Real frames for Buster, Raven, Volt and grunt: `ArtSource/proto_v3/v2/anim/<char>/stage1/frames/{down,up,side}/{idle,run,shoot}/*.png` + `<char>_stage1_meta.json` (fps, loop, flip_x_for_left, pivot). Import under `Assets/HillNGun/Proto/Art/v2/anim/<char>/stage1/...` (Point filter, no compression, Sprite single, custom pivot). Only idle/run/shoot needed now (stage2 and grunt down: skip). Data: a ScriptableObject per character (e.g. `ProtoFlipbookSet`) with clips keyed by (facing, anim) holding sprites/fps/loop/flip; an editor builder (in or next to `ProtoPixelArtSetup`) that reads the meta JSON and builds the SOs + applies importer settings; referenced from `ProtoPixelArt` (TopDown and Frontline). Missing clip → fall back to the current static pose sprite.
7. Runtime: a `ProtoFlipbookAnimator` (view only) + a pure, testable facing/anim selector (static class, no MonoBehaviour) that takes (moveVec, aimVec, isAiming/isShooting, currentFacing, timeSinceChange, dt) → facing, anim, playback rate. Player, allies, enemies, grunts and Frontline bots all use the same selector (bots feed their move/aim vectors). Replace the old pose swap / temp bounce for these four characters.
