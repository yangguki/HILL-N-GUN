## 0. 기획 조정 (11/20) — 먼저 반영
- 이동 존: 발 x 범위 **22–78%** (y 75–90% 유지). `Proto_GreyboxMoveZone` 갱신, 기존 이동 테스트 기대값 갱신.
- 근거리 상자: **x 58–69%**, y 62–82%(높이 20% 유지). 중단·원거리 상자는 그대로. `Proto_GreyboxStageBuilder`/레이아웃 상수 갱신, `Build_MatchesLayoutRatios` 기대값 갱신.
- 엄폐 테스트(`Cover_BlocksHeadOnBullet_AllowsGlancingHit`): '상자 뒤' 플레이어 x 를 새 근거리 상자 중심(**63.5%**)으로, '빗겨 맞는' 대조 x 는 상자와 겹치지 않는 위치(예: **40%**)로 갱신. 발 y 84% 유지. 테스트 의도는 유지.
- HUD 는 위치 유지.

## 1. 적 자리 HP (임시 타깃)
- 작업 1의 적 자리 마커 8개를 `Proto_GreyboxTarget`(순수 로직 + 컴포넌트)로: HP **3**(6절 적 HP), 피격 시 짧게 흰색 깜빡임, HP 0이면 숨김(비활성). 지면 히트박스 = 발 위치 기준 폭(몸폭) × 깊이 띠(작업 2 플레이어 footprint 와 같은 방식, 깊이 스케일 반영).
- 점수: 처치당 +100, HUD SCORE 갱신.

## 2. 조준 (3.2 권장안)
- `Proto_GreyboxAim`(순수 로직): 살아 있는 타깃 중 **플레이어 발에서 가장 가까운**(지면 거리) 타깃 자동 선택. 동률이면 x 가 더 가까운 쪽.
- 드래그 보정: 화면 오른쪽 절반(HUD 버튼 위 제외)에서 마우스/터치 드래그하면 조준점 오프셋(지면 좌표, 최대 ±1.5 유닛 x / ±0.6 y)을 더한다. 손을 떼면 0.3초에 걸쳐 오프셋 0으로 복귀. 보정 중에는 오프셋 위치에서 가장 가까운 타깃으로 재선택 가능.
- 조준점(작업 1 크로스헤어)이 매 프레임 현재 조준 위치(타깃 몸 중심 화면 위치 + 오프셋)로 따라간다. 타깃 없으면 기본 위치 (50%, 38%).

## 3. 발사·재장전 (3.3, 6절)
- 발사: J 키 / 마우스 왼쪽 클릭(드래그 시작이 아닌 클릭) / FIRE 원 버튼. 누르고 있으면 연사, 발사 간격 **0.33초**.
- 아군탄: **노란 원, 지름 0.15 유닛, 속도 14 유닛/초**. 플레이어 발 → 조준 지면 위치 방향으로 직진, 타깃 footprint 에 닿으면 피해 1. 그림은 깊이 스케일로 **멀어질수록(지면 y 가 커질수록) 작아짐**. 화면 밖/사거리 끝이면 소멸. 원거리 상자(울타리 너머)·중단 상자에 막힐 수 있음(엄폐 로직 재사용, 아군탄은 플레이어보다 앞쪽 상자만 판정 — 플레이어가 서 있는 바로 뒤 상자는 무시해도 됨: 탄 출발점에서 0.3 유닛 이내 교차 무시).
- 탄창 **6발**, 비면 자동 재장전, R 키 / 재장전 버튼으로 수동 재장전, 재장전 **1.5초**, 재장전 중 발사 불가. HUD 에 탄 수 표시(예: FIRE 버튼 아래 "6/6", 재장전 중 "R...").
- 로직: `Proto_GreyboxGun`(순수: `TryFire(time)`, `StartReload()`, `Tick(dt)`, `Ammo`, `IsReloading`).

## 4. 수류탄 (3.3)
- G 키 / 수류탄 버튼: 조준 지면 위치로 포물선(그림만 포물선, 판정은 지면 직선) 비행 0.6초 → 착탄 시 폭발 반경 **1.2 유닛**(지면 거리). 반경 안 타깃 피해 **3**, 반경 안 상자(원거리/중단/근거리 모두 대상) **파괴**(비활성, 해당 엄폐 rect 제거). 쿨다운 **8초**. 상자 1개당 수류탄 1발로 파괴.
- 폭발 표시: 주황 원이 0.3초간 커졌다 사라짐.
- 로직: `Proto_GreyboxGrenade`(순수) + `Proto_GreyboxCover.RemoveCrate(...)` 또는 상자 활성 플래그.

## 5. 튜닝
`Proto_GreyboxTuning` 에 추가 (`[SerializeField]` 로 컨트롤러에 노출): 아군탄 속도 14, 지름 0.15, 발사 간격 0.33, 탄창 6, 재장전 1.5, 적 HP 3, 수류탄 쿨다운 8, 반경 1.2, 수류탄 피해 3, 드래그 보정 최대 x 1.5 / y 0.6.

## 6. 테스트 (EditMode, 새 파일 `Proto_GreyboxCombatTests.cs`) — 아래 4가지만 (+ 0절 기존 테스트 기대값 갱신)
1. 최근접 타깃 선택: 플레이어 발 위치를 바꿔가며 가장 가까운 살아 있는 타깃이 선택됨; 그 타깃이 죽으면 다음 가까운 타깃.
2. 탄 이동·스케일: 14 유닛/초로 dt 스텝 후 이동 거리 ≈ 14·t; 지면 y 가 커질수록 그림 스케일이 작아짐(단조 감소); 타깃 footprint 에 닿으면 타깃 HP −1.
3. 재장전: 6발 발사 후 7번째 불가 → 자동 재장전 시작, 1.49초엔 아직 0발, 1.5초 후 6발; 수동 재장전(R) 동작; 재장전 중 발사 불가.
4. 수류탄 상자 파괴: 근거리(또는 중단) 상자 위치로 던짐 → 착탄 후 상자 비활성 + 엄폐 판정에서 제거(그 뒤로 오는 탄이 더 이상 막히지 않음); 반경 안 타깃 HP 감소, 반경 밖 타깃 그대로; 쿨다운 중 재투척 불가.
기존 테스트 6개도 통과해야 함.
