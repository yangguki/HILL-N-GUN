## 1) Restart bug (다시하기 → error banner)

**Root cause.** `FullRestart()` calls `StageBuilder.Build()` → `ClearRoot()`, which destroyed *every* child of the stage builder. The 3D `Greybox3D_ViewRoot` was parented under that builder, so restart destroyed the 3D stage.

The presenter registry kept a `Proto_Greybox3DViewHost` whose `_presenter` still pointed at the destroyed MonoBehaviour. In play mode `Destroy()` is deferred to the end of the frame, so the new player could even bind to a soon-to-be-dead presenter. On the next `Sync`, `ViewHost` used the C# `?.` operator, which does **not** use Unity’s overloaded `==` and will invoke methods on a destroyed object. That threw `MissingReferenceException`, `Proto_Greybox3DFault.Report` drew the red banner, and 3D looked broken (2D itself was usually still running).

This is an in-place reset (no scene reload). Switching 2D/3D after a broken restart also hit the dead presenter.

**Fix.**

- `ViewRoot` is now created at the **scene root**, not under `StageBuilder`.
- `ClearRoot()` also skips any child named `Greybox3D_ViewRoot` as belt-and-suspenders.
- `ViewHost` treats a destroyed presenter as missing (Unity `==`), recreates it, calls `SetActive(true)`, and never uses `?.` on it.
- A successful 3D `SetActive` / rebuild calls `Proto_Greybox3DFault.Clear()` (and `SetFaultLine` now uses `DestroyImmediate` in edit mode so tests stay clean).

Restart works repeatedly in 3D and 2D, and 2D/3D switching after restart works. Regression: `Restart_ThreeTimesIn3D_DoesNotThrow_AndKeepsSingleViewRoot` (also Sync-after-destroy and a 2D/3D toggle after the third restart).

## 2) Roll distance

Travel still comes only from shared `Proto_GreyboxRoll` / `PlayerMotor.ApplyDelta`. The 3D presenter does not add its own displacement; it just maps the sim foot through `FootToWorld`.

Two things made 3D look too long:

- `RollDistance` was still **2.2** world units after the size pass (~4.2 mid-band body widths; the move-speed rescale had not retuned roll).
- The depth map used `DepthZFar = 22`, so 1 unit of sim Y became ~4 units of ground Z. A forward roll looked several times longer than the same roll in 2D.

**Final values.**

- `RollDistanceBodyWidths` = **2.75** (in the 2.5–3 Brawl-dash range)
- `RollDistance` = **1.44** world units (2.75 × mid-band width 0.5227)
- Same constant in 2D and 3D
- `DepthZFar` **22 → 14** so forward rolls and the street itself are tighter (dz/dy ≈ 2.55 instead of 4). Horizontal rolls already matched 2D 1:1.
- DBG slider **“Roll distance (body widths)”**, range 1–5, default 2.75. It writes `tuning.RollDistance = bodyWidths × HeroVisibleWidthAtMidBand()`; `ApplyRuntimeTuning` already pushes that into the shared roll each tick.

Forward 3D travel is still a bit longer than 2D on screen because some depth compression remains (needed so the fence and town still recede). It is no longer the old ~4× exaggeration.

## 3) Bullet look

3D bullets are no longer stretched glow-spheres with a 90° tilt.

- **Ally:** small yellow-gold body, rounded brass tip, thin dark cel outline, short yellow streak. Elongated along +Z (travel) and oriented with velocity.
- **Enemy:** larger red/orange glowing body, white-hot core, red trail. Also oriented along velocity.
- Both sit above the warmer dirt so yellow/gold and red/orange read with strong contrast.

Sizes are unchanged from slice E (ally visual ≈ 0.25 hero width, enemy ≈ 0.33).

## 4) Closer to the concept

- Ground is warm orange-brown dirt (sand noise mid-range, no blown-out yellow; key light 1.02 instead of 1.22).
- Vignette softened 0.32 → **0.10**; warmth raised to **0.14** for a slightly saturated grade.
- Deeper blue sky (`_UseTex` 0.18 → 0.08 so the pale skybox does not wash the dome), brighter/puffier white clouds.
- Redder layered mesa bands on the horizon.
- Storefronts scaled down (height ~1.85–2.17, was ~3.35+) and lined along both sides of the street (4 left, 4 right, 3 smaller in the back) with wooden faces and colored awnings.
- Near-player wooden crate is cover-sized (~chest height). Fence still has a mid-screen gap. Cacti are a more saturated green.

2D art was not restyled.
