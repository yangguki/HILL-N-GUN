## 런 A — 크기 (이번 프롬프트의 범위)

1. 플레이어 프리팹 **높이만** 27% → **19%**. 발은 계속 y ≈ 88% (`PlayerNearFootWorldY = 1.2`). 머리 y ≈ 69%.
   - `Proto_GreyboxTuning.PlayerCapsuleHeightPercent` 27 → **19**.
   - 몸폭은 높이에 비례: `PlayerCapsuleWidthPercent` 8 → **5.6** (8 × 19/27). 히트 모양(콜라이더/캡슐)도 같이 비율 축소.
   - **전역 근/원 스케일 `DepthNearScale = 2.5` 는 바꾸지 않는다.** 상자·적 높이 11%·울타리 크기도 바꾸지 않는다.
2. 적탄 지름 0.55 → **0.30 wu**. 주황 소프트 글로우를 절차적으로 추가(코어 + 반투명 할로). 깊이 스케일은 기존처럼 가까울수록 커짐.
3. 아군탄 지름 0.15 → **0.09 wu**. 하한 화면 높이 **0.6%** (≈0.06 wu, `MinAllyBulletWorldDiameter`) 유지. 얇은 노란 트레이서 길이를 **0.50 wu** 로 맞추고 두께를 시안처럼 가늘게.
4. `Proto_GreyboxRuntimeTuning` 슬라이더 기본값을 새 상수와 같게. 슬라이더 범위가 0.30/0.09 를 못 담으면 범위만 최소 조정.
5. 테스트 기대값에서 27/0.55/0.15/몸폭 8 등 크기 하드코딩을 새 값으로 갱신. 기존 13개 EditMode 테스트가 논리상 통과해야 한다. **Unity를 실행해 테스트를 돌리지는 말 것.**
6. `docs/handoff/2026-11-20-v4-greybox-scope.md` 를 박스 문서와 같이 갱신. 바뀐 값 옆에 **`(11/20 사용자 피드백 조정)`** 표기. 전역 스케일 2.5 유지, 플레이어 높이만 19%임을 분명히.

끝나면: 수정 파일 목록, 바뀐 상수, 테스트에서 고친 기대값을 짧게 출력.

## 런 B — 룩 (런 A 이후, 별도 프롬프트)

시안(`screen_combat.png`, `screen_cover_roll.png`)에 가깝게, **값싼 절차적 스프라이트**로만.

- 팔레트: 채도를 낮춘 회청·먼지색. 채색은 플레이어 보라, 그런트 빨간 두건, 탄, FIRE, HP만 (`spec.md` 5절).
- 플레이어: 등 뒤 실루엣(모자·어깨·총팔). 보라 캡슐/박스가 아니게.
- 그런트: 같은 회청 복장 + 빨간 두건. 빨간 사각 덩어리 아니게. 발 아래 소프트 그림자.
- 상점 파사드에 문이 보이게(스폰 지점). 울타리는 포스트+레일(철로처럼 얇고 촘촘하지 않게).
- HUD: 반투명 원, 상단 솔리드 바 제거, SCORE / STAGE 1 · WAVE n/3 / DBG / 일시정지, FIRE는 노란 채움, 탄약 핍, HP 바 레이아웃은 시안·spec 3절.
- 구르기 잔상은 있으면 시안처럼 유지/보강(이미 있으면 최소 수정).

새 아트 파이프라인 없음. 범위 밖 항목은 건드리지 않음.

## 런 C — 결과 화면 (런 B 이후, 별도 프롬프트)

알려진 버그: 어두운 패널만 보이고 CLEAR/DOWN, 점수, 웨이브, 생존 시간, 재시작 안내 글자가 안 나온다. 로직·재시작은 동작한다.

시안 `screen_result.png` + spec 4절:

- 패널 x **28–72%**, y **16.5–80%**. 어두운 카드 `#10121A` 약 92%, 얇은 테두리.
- 타이틀 `STAGE CLEAR` (`#F5DC8C`) 또는 `DOWN` (`#D67070`). 게임에서는 둘 중 **하나만**.
- 스탯: SCORE, WAVE n/3, 생존 시간, 처치. 힌트 문구 그대로: `R  /  탭하여 다시 시작`.
- 글자는 패널 **앞**에 그려지게(sorting / canvas / alpha / 파괴된 플레이어 참조로 사라지지 않게).
- 한글 글리프가 프로젝트에서 값싸게 되면 한글 라벨 사용(Gothic A1 또는 Noto Sans CJK). 안 되면 영어 라벨로라도 **빈 화면은 남기지 말 것** (SCORE / WAVE / SURVIVAL / KILLS / `R  /  TAP TO RESTART`) 하고 한글 불가 이유를 보고.
- `Proto_GreyboxScreenshot`에 `CaptureTask5Sequence()` 추가: 1280×720, `Builds/v4_task5_combat.png` (웨이브 진행·적탄·아군탄 보이게), `Builds/v4_task5_result.png` (결과 글자가 보이게). Unity 실행은 하지 말 것.

끝나면: 결과 화면 수정 요지, 한글 가능 여부, 스크린샷 메서드 시그니처를 짧게 출력.
