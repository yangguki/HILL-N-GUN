# Greybox 3D view slice A (2026-11-22)

Local branch: `proto/v4-3d-view` (not pushed). Based on `6f7032c` (`proto/v4-greybox-stage`, already on origin).

## Architecture

- All combat / motor / wave logic remains in `Assets/HillNGun/Proto/Greybox/`.
- New view layer lives under `Assets/HillNGun/Proto/Greybox3D/` (`HillNGun.Proto.Greybox3D` asmdef → references Greybox only).
- Thin Greybox hooks: `Proto_GreyboxViewMode*`, `IProto_GreyboxViewPresenter`, `Proto_GreyboxWorld2DVisibility`, DBG toggle in `Proto_GreyboxRuntimeDebugUi`, `Proto_GreyboxPlayerController.SetViewMode` / `ApplyViewMode`.
- Greybox3D registers a factory at load (`Proto_Greybox3DViewBootstrap`). `Proto_Greybox3DViewPresenter` reads live controller state each frame and draws placeholders.
- Default view: **2D**. Toggle **「View: 2D / 3D」** in the F1 DBG panel. Choice persists via `PlayerPrefs` key `HillNGun.Greybox.ViewMode` (EditMode tests use an in-memory scope, same pattern as bullet-speed prefs).
- Pause / result screen toggle was not added (DBG only).

## Switch behavior

- **Live switch** mid-run (hearts, ammo, waves, score preserved). 2D sprites + ortho world camera hidden; uGUI HUD is retargeted to the active world camera.
- No stage restart required for view change.

## 2D → 3D mapping

`Proto_Greybox3DFootMap`:

- `foot (x, worldY)` → `(x, 0, z)` where `z = Lerp(0, 22, InverseLerp(playerNearFootY, enemyFarFootY, footY))`.
- Player near band uses `MoveFootMaxPercent` (95%); enemy far row uses `PerspectiveEnemyFootMinPercent` (40%); fence uses `FenceBottomPercent` (59% with perspective on).
- Character height uses existing `Proto_GreyboxPerspectiveDepth` screen-% helpers converted to world height.

## 3D slice contents (placeholders, no external art)

Unity primitives + shared cel material, chibi proportions:

- Raven-like hero: big purple hat (crown + brim), purple shirt, red bandana, blue pants, revolver.
- One grunt type: brown hat, red bandana, tan shirt (procedural mesh; see leftovers).
- Wood crates, fence with a center gap and posts, dirt ground, storefront row with colored awnings / windows / doors, cacti, mesa blocks, gradient sky sphere (Cull Front).
- Perspective camera behind the player (player bottom-center, looking down the street toward the fence and town). Gentle X follow; snaps in EditMode captures.
- Bullets: ally = small yellow capsules, enemy = larger orange-red capsules (pooled).
- Procedural motion: idle bob, move lean, roll Y-spin (no rigged clips).
- Aim: 3D ground marker. 2D aim line / cone / grenade arc are hidden in 3D.

## Render pipeline

**Built-in Forward** — unchanged (`GraphicsSettings` custom RP unset). Do not switch the project to URP/HDRP.

Custom ShaderLab `HillNGun/Proto/Greybox3D/Cel` (wrapped Lambert ramp) and `HillNGun/Proto/Greybox3D/Sky` (unlit gradient, Cull Front). **No outline pass** in this slice. Fallback `Unlit/Color` if a shader is missing in batch.

## Leftovers / risks

- Grunts (and enemy red/orange bullets) are wired in the presenter but were hard to see in the captures — likely too small / depth-compressed beyond the fence, or briefly hidden if a popup slot is down. Needs a visibility pass (min height, contrast, confirm SyncGrunts in a live APK).
- Sky gradient is pale (horizon-heavy because the camera looks slightly down). Backdrop / stronger zenith bias would help.
- 2D half of the compare stitch is missing the uGUI HUD (ortho `cam.Render` + ScreenSpaceCamera). 3D half has HUD.
- Live 2D sprite sync still runs under 3D (sprites hidden each frame) — minor CPU cost; could gate later.
- Camera handoff between ortho/perspective may flicker on slow devices.
- Grenade arc is still 2D-only (hidden in 3D). No 3D grenade / explosion mesh yet.
- Cel placeholders only — no rigged mesh, no outline.
- Pause/result view toggle not added.
- Target 60 fps on mid Android was not instrumented in this pass; primitive counts are low (one directional light, no shadows, pooled bullets) but should be checked on device.
