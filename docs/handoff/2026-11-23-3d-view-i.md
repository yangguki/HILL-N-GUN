## What got mapped

### HUD / UI (3D view only; 2D layout/hit tests unchanged)
- Designer joystick, attack, skill (grenade/bomb), reload, and pause skins, laid out in concept 1920×1080 space converted into the existing 1280×720 percent hit-test space (`Proto_Greybox3DHudLayout`, enabled only while the 3D skin is applied).
- Attack = fire; skill = grenade; roll kept as the existing control (not reskinned to a missing function). Aim has no gameplay function, so the aim button is hidden.
- SCORE / STAGE image labels + numerals (Lilita One TTF; TMP when a font asset can be created, otherwise UI.Text + Outline).
- HP: existing 3-heart model displayed as a designer HP gauge split into 3 segments, using `FillForHeart` for regen partial fill.
- Crosshair + `_hit` flash on score increment.
- Settings gear hidden in 3D. A small leftover **DBG** chip can still appear under SCORE (runtime debug widget; Hide in Apply does not always stick if it is recreated after skinning).

### FX
- Ally/enemy bullet sprites + streak/trail billboards.
- Muzzle flash, hit spark, explosion + smoke, coin (catalogued).
- 3rd-roll dizzy: v2 star-ring sheet (8 frames @ 12 fps), ~0.9 m wide, 0.35 m above the head bone; procedural stars only if the sheet is missing. 2D `Greybox_DizzyStar` is hidden in 3D.
- Roll dust prefers v2 puff (16 fps) and falls back to the v1 dust sheet.
- Shield bubble (8 @ 12 fps), shield pop, and shield sphere textures are **imported and catalogued only**. There is no shield mechanic; nothing was invented.

### Environment / props
- Designer tiles on buildings (wood wall, shingle roof), dirt ground, wood deck (`PorchDeck`), mesa rocks, and storefront awnings.
- V2 street props (cutout shader, alpha clip 0.5, mip coverage preserved): cart + wheel, lamp post + glow sprite, red/white stall awning + edge strip, fence segments, rock piles. `hng_env_atlas_main_v2.png` cells 9–14 are catalogued.
- Existing atlas cells 0–8 and tile sizes were not changed, so previously mapped UVs still hold.

### Characters (intentionally unchanged)
- Slice H Kenney Mini meshes, clips, and Kenney colormaps remain. Designer colormaps (`hng_char_player_*`, enemy variants, `playermaleg`, turret) are imported under `Greybox3D/Art/Characters/` and assigned on the catalog for later, but **not applied** to any mesh.
- No cowboy hats, designer guns, bandanas/goggles, or 1.25× strong scale.
- Turret: no combat enemy type exists to replace (`Strafe` / `Popup` only). Per the later instruction it was **not** placed as a static display either.

- **Sky** is still the simple cel dome + two clouds, not the painted concept sky.
- **Wood wall tiling** is a little repetitive on long facades (scale/UV, not a broken atlas cell).
- Shield bubble/sphere: unused until a mechanic exists. Designer preferred the 8-frame bubble over the sphere.
