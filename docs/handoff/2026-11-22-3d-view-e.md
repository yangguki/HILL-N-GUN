## Polish (characters, town, FX, light)

- **Silhouettes / dress.** `Proto_Greybox3DDressFollow` parents hat, hair, bandana knot, and belt to the body in `LateUpdate` (upright yaw, world scale 1). The revolver uses `AttachLocal` on `Fist.R`. The red bandana knot sits at the nape so it reads from behind. Rim light comes from the shared cel material (`_RimStrength` 0.22).
- **Hits and death.** `Proto_Greybox3DCombatFx` (instanced `sharedMaterials`, no `.material` leak in EditMode): white hit flash, knockback, death = fall + fade over 0.58s (no blood). Roll is a procedural tuck + dust, because the Quaternius pack has no roll or death clip (takes: Idle, Walk, Walk_Carry, Shoot_OneHanded, RecieveHit, Punch). Tuck must preserve the `FitHeight` base scale so the FBX (often scale 100) does not pop to full size.
- **Grunt variants.** Three hat/shirt tint sets; `BuildGrunt(parent, idx % 3)`.
- **Town charm.** Nine storefronts (three per side + three at the back), plank posts, hanging icon signs, window frames, scalloped awnings, barrels, crates, hay bales, a procedural water tower (`Greybox3D_WaterTower` at (7.6, 0, 16.5)), tumbleweeds, extra mesas with color bands, puffier clouds, and a procedural 128px `SandNoise` on the shared ground (tiling 14×18).
- **Sky / atmosphere.** Deeper blue (zenith 0.10, 0.38, 0.94; horizon 0.42, 0.70, 0.96; `_UseTex` 0.18), 28 dust motes, Built-in cheap vignette blit on the 3D camera.
- **Combat FX.** Muzzle flash, ejected casings, crate impact puffs, grenade puff + shockwave + a small screen shake, roll dust. Ally shots are small yellow tracers; enemy shots are a slightly chunkier glow (see sizes below).
- **Lighting.** Warm key 1.22, cool fill 0.34, ambient flat (0.42, 0.36, 0.32).

2D play and the pause / 설정 **2D / 3D** toggle from slice D are unchanged. Default launch is still 2D.

## Feel: size and move speed (Brawl Stars reference)

Landscape Brawl Stars shows about 9–10 tiles vertically, and a brawler is ~1 tile, so a brawler is ~10–12% of screen height. “Normal” move speed is ~720 units/s on a 300-unit tile ≈ 2.4 tiles/s ≈ **2.4 body-widths per second**. Projectiles are small, roughly 1/4–1/3 of a brawler’s width.

Final baked values (perspective on, mid-band foot **78.5%** from the top):

| Quantity | Value |
|----------|--------|
| Player height at far / top of move band | **9%** of screen height |
| Player height at near / bottom of move band | **12%** of screen height |
| Player height at mid-band | **10.5%** |
| Player capsule width | **3.36%** of `WorldWidth` (old 5.6% × 12/20, aspect kept) |
| Mid-band visible body width | **0.5227** world units (`WorldWidth` 17.778 × 0.0336 × 10.5/12) |
| `MoveSpeed` | **1.25** world units/s (**2.4 × 0.5227 = 1.254**, baked 1.25) |
| Previous `MoveSpeed` | 4.2, then 2.03 at the old 20% height |
| Grunt height far / front row | **6% / 8%** (front row still reads past the fence) |
| `TargetHeightPercent` / flat enemy height | **8%** |
| Ally bullet visual and hurtbox | **0.13** ≈ 0.25 × mid hero width; tracer length **0.32** |
| Enemy bullet visual and hurtbox | **0.17** ≈ 0.33 × mid hero width; diameter mul **1.0**, glow mul **1.45** |
| 2D crate heights (feet unchanged) | **3.6% / 6.6% / 12%** (far / mid / near) |
| Fence | Bottom landmark stays **59%**; top **56%** (height 3%) |
| 3D prop scale (crates, barrels, fence, hay) | **0.6** (12/20) |
| 3D character mins | Hero **0.85**, grunt **0.65** so `CharacterHeightAtFoot` wins (~1.14 near, ~1.00 mid, grunt front ~0.74) |
| 3D camera | Desired `(hero.x*0.05, 2.55, hero.z-4.85)`, look-at `hero+(0, 0.72, 9.2)`, FOV 48 |
| Walk cycle | 1.25 mid-band body widths; 3D playback follows ground speed so feet do not slide |

The 2D and 3D views share `Proto_GreyboxPlayerMotor`. The vertical depth factor (`move.y *= PlayerVerticalMoveSpeedFactorAtFootPercent`) is unchanged. Hurtboxes follow the new visuals. 3D bullets no longer use the old hardcoded 0.62×1.25 capsules; they take the runtime / tuning diameters.

### DBG sliders

- **Move speed** — 0.6–6, default 1.25.
- **Player h top %** — 5–16, default 9.
- **Player h bottom %** — 8–22, default 12.
- Changing either height slider recomputes `MoveSpeed = 2.4 × HeroVisibleWidthAtMidBand()` so the 2.4-widths/s feel stays.
- **Ally bullet size** — 0.05–0.4, default 0.13.
- **Enemy bullet size** — 0.06–0.5, default 0.17.

## How to switch (player-facing)

Default launch is still **2D**.

1. Pause (top-right pause icon) → tap the large **2D / 3D** button under the title → Resume.
2. Or Pause → 설정 / SETTINGS → the same **2D / 3D** button above 닫기 / CLOSE.
3. DBG **View: 2D / 3D** still works (F1 / DBG button).

The choice is saved in PlayerPrefs `HillNGun.Greybox.ViewMode`.
