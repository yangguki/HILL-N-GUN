## 요약
- 뷰 모드에 `View2DChibi = 2`를 추가했습니다. 한 빌드 안에서 **2D 픽셀 → 3D → 2D 치비 → 2D 픽셀** 순서로 바뀝니다.
- 2D 치비는 스킨/렌더링만 바꿉니다. 게임 로직, 하트 3칸, 웨이브, 탄창(5발)은 그대로입니다.

- HUD: 하트 3칸 HP 게이지, SCORE/STAGE 판넬, ATTACK / ROLL / SKILL / RELOAD 버튼, 탄약은 "n/5" 텍스트로 표시합니다.

## 토글 방법
- 일시정지 메뉴나 설정 화면의 **"View:"** 버튼을 누를 때마다 `2D 픽셀 → 3D → 2D 치비` 순서로 바뀝니다.
- 버튼 라벨: `View:  2D 픽셀` / `View:  3D` / `View:  2D 치비`. 한글 폰트가 없으면 ASCII 라벨로 대체합니다.
- 버튼 색상: 픽셀 / 3D / 치비(주황)가 각각 다릅니다.
- 선택한 값은 PlayerPrefs에 저장되어 다음 실행 때도 유지됩니다.
