## A. 아군탄·폭발 가시성 (먼저)
작업 3 캡처에서 날아가는 노란 아군탄과 폭발 원이 화면에 안 보였다(판정·점수·상자 파괴는 정상). 원인을 찾아 고친다: sortingOrder(땅 -400대, 건물 -450, 울타리 -390 보다 **앞**에 그려야 함 — 탄·폭발은 예: +200 이상), z 위치, 스프라이트/스케일 0, 생성 직후 비활성화 등.
- 아군탄: 작게 유지하되 **화면 높이의 최소 ~0.6%**(≈0.06 유닛) 이상으로 그린다(깊이 스케일로 더 작아지더라도 하한 적용). 노란색 + **짧은 트레이서 꼬리**(탄 뒤로 진행 반대 방향 0.4–0.6 유닛, 반투명 노랑 얇은 막대 또는 LineRenderer 없이 늘인 스프라이트).
- 폭발: 착탄 지점에서 주황 **원**이 약 **0.3초** 동안 커지며(반경 1.2 지면 유닛 기준, 깊이 스케일) 투명해짐. 정렬은 앞쪽.
- 적탄(B)도 같은 정렬 규칙.

## B. 작업 4 — 적 웨이브·슬라이더 (4절·6절)
### 적 (그런트 1종)
- 작업 3의 고정 적 자리(`Proto_GreyboxTarget` 마커 8개)를 **웨이브 스폰 그런트**로 대체(타깃·조준·HP 로직은 재사용: `Proto_GreyboxTarget` 를 그런트가 갖거나 상속). 모양: 빨간 캡슐/사각 도형, 높이 11%(적 열 발 y 37%), 깊이 스케일.
- 스폰 지점: 상점 문(건물 블록 하단 중앙들, y ~32%) 과 거리 양 끝(x 0% / 100%, 적 열 y). 스폰 후 적 열(발 y 37%, x 21–79% 안의 비어 있는 자리)로 걸어가 자리 잡음.
- 웨이브 **1/2/3 = 3/5/8명**(6절). 웨이브 내 전원 처치 → 1.5초 후 다음 웨이브. HUD "STAGE 1 · WAVE n/3".
- 행동(단순): 자리에서 좌우 **스트레이프**(±0.6 유닛 왕복) 또는 **팝업**(원거리 상자 x 범위 근처 자리면 상자 뒤에 숨었다 나와서 쏨: 숨어 있는 동안 피격 불가·발사 안 함). 각 그런트에 랜덤(시드 고정 가능) 배정.
- 발사: **적 발사 간격 1.6초**(개체별 위상 랜덤), 발사 순간 플레이어 **발 위치를 향해** 지면 직선. 적탄: **크고 느린 빨강·주황 원(근거리 기준 지름 0.55, 속도 3.5)**, 깊이 스케일로 가까울수록 커짐. 작업 2의 엄폐(상자 차단)·구르기 무적 규칙 적용. 맞으면 HP −1(HUD 갱신), 짧게 플레이어 흰색 깜빡임.
- 로직 클래스: `Proto_GreyboxWaveDirector`(순수: 웨이브 번호, 스폰 큐, `Tick(dt)`, 스폰 수, 클리어 판정), `Proto_GreyboxGrunt`(순수 상태: 위치, 이동, 스트레이프/팝업, 발사 타이머), 뷰는 컨트롤러/별도 MonoBehaviour.

### 결과·재시작
- 3웨이브 클리어 → "CLEAR" / HP 0 → "DOWN" 결과 패널(점수, 웨이브, 생존 시간). R 키 또는 화면 탭/클릭 → 씬 상태 리셋 후 재시작(씬 재로드 대신 빌더 재빌드 + 상태 초기화 권장; Build Settings 필요 없게).

### 디버그 슬라이더 패널
- F1 키 또는 좌상단 작은 "DBG" 버튼으로 토글. uGUI Slider(또는 IMGUI `OnGUI` — 단, 배치 캡처에 찍혀야 하므로 uGUI 권장, Screen Space - Camera 캔버스).
- 6절 항목 전부: 이동 속도, 구르기 거리/시간/무적/쿨다운, 적탄 속도/크기, 아군탄 속도/크기, 발사 간격, 탄창, 재장전 시간, 적 수(웨이브 1/2/3), 적 발사 간격, 적 HP, 플레이어 HP, 수류탄 쿨다운, 엄폐 피해 감소(0–100%), 근/원 스케일 비. 각 행: 이름 + 슬라이더 + 현재 값.
- 값은 **런타임 튜닝 객체**(`Proto_GreyboxRuntimeTuning` 인스턴스, 기본값 = `Proto_GreyboxTuning` 상수)에 저장하고 로직이 매 Tick 그 값을 읽어 **즉시 반영**(예: 이동 속도 변경 → 다음 Tick 이동 거리 변화; 적 수 변경 → 다음 웨이브부터; 탄창 변경 → 다음 재장전부터 OK).
- 엄폐 피해 감소 < 100% 면 상자에 막힌 탄도 (1−감소율) 확률/비율 피해 — 단순히 정수 HP 이므로 "감소율 미만 확률로 1 피해"(시드 고정) 정도로.

## 테스트 (EditMode, 새 파일 `Proto_GreyboxWaveTests.cs`) — 아래 3가지만
1. 웨이브별 스폰 수: 디렉터를 dt 스텝으로 돌려 웨이브 1/2/3 에 3/5/8 명 스폰(전원 처치 시뮬 후 다음 웨이브), 3웨이브 클리어 후 종료 상태.
2. 적탄이 플레이어를 향함: 여러 플레이어 위치에 대해 그런트 발사 탄의 지면 속도 방향과 (플레이어 발 − 발사 위치) 방향의 각도 < 2°, 속도 크기 = 런타임 적탄 속도.
3. 슬라이더 값 플레이 중 적용: 런타임 튜닝에서 이동 속도를 바꾸면 다음 Simulate/Tick 이동 거리가 바뀜; 적 발사 간격을 바꾸면 이후 발사 간격이 바뀜; (가능하면) 실제 슬라이더 UI 의 value 를 바꿔 onValueChanged 로 런타임 튜닝이 갱신되는 것까지.
기존 테스트 10개도 통과 유지(작업 3 테스트가 고정 적 자리에 의존하면 그 테스트가 쓰는 타깃을 테스트 안에서 직접 생성하도록 최소 수정 OK, 기대값·의도는 유지).
